身份校验规则

主动指令要求发件人在允许列表内，直接回复要求来自原通知或原回信的收件地址。QQ 自发自收检查「已发送」副本。外部地址采用 QQ 的 DMARC 校验，已关联的回复或显式启用了 SPF 的允许地址也可通过 QQ 的 SPF 校验。

处理或跳过邮件后保存本机 UID，其他设备仍可读取。每台设备应使用独立名称，重名设备都可能执行同一封指令。暂时故障会保留收件进度，约 30 秒后进入下一轮。

定位会话与执行 Codex App Server

如何定位会话？

主动指令可用 [AI会话] 或 [AIChat]，后者忽略大小写。

按名称

[工作目录名][会话名] 或 [会话名]，后者默认 Global。先按工作目录查找现有会话，再按旧项目名回退。可恢复归档会话，找不到时可新建。

按 ID

单段为完整 [会话ID] 时，直接查找已有会话，包括未归入项目的会话。

直接回复

优先查本机登记的 In-Reply-To。缺少时查 References，两者均缺失时凭带已登记续聊码的完整主题查找。仅提交新增正文。

登记回信信息，再提交给 Codex

登记已验证的发件人、邮件回复头和加密后的本轮问题。来信中的无地址通知请求使用自动回信。默认地址的修改在本机 Codex 中处理。

该轮完成 → 生成完成回信

按本轮用户消息追踪完成记录。尚未完成时，保留记录并在后续轮询中检查。

定位或提交失败时

已验证的主动指令确定无法提交 → 登记失败回执。无法关联或无法路由的直接回复 → 跳过。连接等暂时故障 → 下一次轮询重试。
